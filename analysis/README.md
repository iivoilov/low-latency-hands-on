# Runtime analysis output

Receiver reports, source/build metadata, raw packet timestamps and clock anchors
are generated here and ignored by Git. Use fresh output paths so failed trials
and earlier measurements remain intact.

The source tree includes reviewed [reports and JSON/CSV result tables](../docs/experiments/README.md).
Raw captures are not distributed. Generated PCAP/manifest pairs can be recreated
from the [profile recipes](../simulator/play_files/README.md).
